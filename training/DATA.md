# 학습 데이터 만들기 (스템 형식)

Sound Manager AI는 사용자의 곡에서 세 가지를 배웁니다.

| 배우는 것 | 필요한 파일 | 도구 | 결과 |
|---|---|---|---|
| 악기별 **처리 방식**(게인, 게이트, EQ, 디에서, 컴프, 새츄레이션, 엔벨로프, 리버브) | 원본 트랙 + 처리된 트랙 (+ 리버브 리턴) | `smix_learn_mix` | `장르.smxgenre` |
| 악기별 **볼륨 밸런스**와 믹스 안에서의 **톤** | 처리된 트랙(또는 원본) + 완성 믹스 | `smix_learn_mix` | `장르.smxgenre` |
| **마스터 체인**(EQ, 컴프, 새츄레이션) | 마스터링 전 믹스 + 마스터 | `smix_learn_mix` | `장르.smxgenre` |
| **악기 인식**(채널 이름 후보) | 원본 트랙 | `smix_ear_features` → `train_ear.py` | `ear.smxear` |

모두 PC(Mac)에서 돌아갑니다. Colab은 언어 모델 학습에만 씁니다(README 1장).

## 1. 곡 폴더 구조

곡마다 폴더 하나를 만듭니다. 8곡 이상을 권장합니다.

```
songs/
  주님의 사랑/
    raw/                      ← 원본: 플러그인 없이, 페이더·팬 없이
      01_Kick.wav
      02_Snare.wav
      03_HiHat.wav
      04_Tom1.wav
      ...
      12_여성 보컬.wav
    processed/                ← 처리본: 같은 파일 이름, 인서트 플러그인 + 페이더 + 팬 적용
      01_Kick.wav
      02_Snare.wav
      ...
      12_여성 보컬.wav
    returns/                  ← (선택) Aux 리턴: 리버브·딜레이 버스의 출력
      Reverb Hall.wav
      Plate.wav
    주님의 사랑_Mix.wav        ← 완성 믹스(마스터링 전이면 이름에 premaster/mix)
    주님의 사랑_Master.wav     ← (선택) 마스터링된 최종본
  은혜/
    ...
```

규칙은 다음과 같습니다.

- **같은 이름**: `raw/`와 `processed/`의 파일 이름(확장자 제외)이 같아야 짝이 맞춰집니다.
- **같은 시작점과 길이**: 모든 파일을 곡 처음(1마디)부터 같은 길이로 내보냅니다. 플러그인 지연은 자동으로 맞추지만, 시작 위치가 다르면 학습되지 않습니다.
- **같은 샘플레이트**: 한 곡 안의 모든 파일이 같아야 합니다(44.1 kHz 또는 48 kHz).
- **형식**: WAV, 16/24비트 정수 또는 32비트 float, 모노나 스테레오 모두 됩니다. FLAC·AIFF는 먼저 WAV로 바꿉니다.
- **믹스 파일 찾기**: 파일 이름에 `mix`, `믹스`, `premaster`가 있으면 믹스로 읽습니다. `master`, `마스터`, `final`, `완성`이 있으면 마스터로 읽습니다. 하나만 있으면 그 파일을 믹스로 봅니다.
- **자동 제외**: 클릭, 메트로놈, 가이드, 큐, 토크백 트랙은 이름을 보고 자동으로 뺍니다.
- **간단 모드**: `raw/` 폴더가 없으면 곡 폴더의 WAV(믹스 제외)를 모두 원본 트랙으로 보고 **레벨과 톤만** 배웁니다(이전 방식).

## 2. 트랙 이름(악기 라벨)

파일 이름이 곧 악기 라벨입니다. 앞의 번호(`01_`)는 무시합니다. 다음 이름은 역할을 자동으로 알아봅니다.

| 쓰는 이름 | 역할 |
|---|---|
| 남성 보컬, 여성 보컬, Lead Vox, 보컬 | 리드 보컬 |
| 코러스, BV, Backing, 화음 | 백킹 보컬 |
| Kick, 킥 / Snare, 스네어 / HiHat, 하이햇 / Tom1~3, 탐 / OverHead, Room | 드럼 각 역할 |
| Bass, 베이스 기타 | 베이스 |
| 어쿠스틱 기타 / 일렉 기타, Gtr | 기타 |
| 메인건반, 세컨건반, 서드건반, Keys, Rhodes, Organ / Piano, 피아노 | 건반 / 피아노 |
| Pad, 패드 / Strings, 스트링 / Synth, 신스 | 패드 / 현악 / 신스 |

이름이 애매하면 첫 실행 후 생기는 `tracks.csv`에서 라벨을 고치고 다시 실행합니다(`skip`은 제외).

## 3. Logic Pro에서 내보내기

한 곡의 프로젝트를 열고 아래를 차례로 합니다. 모두 **1마디부터 곡 끝까지** 같은 범위로 내보냅니다(사이클 범위를 곡 전체로 지정).

1. **원본(raw)**
   - 파일 › 내보내기 › **모든 트랙을 오디오 파일로…**를 엽니다.
   - **이펙트 플러그인 우회(Bypass Effect Plug-ins)**: 체크합니다.
   - **볼륨/팬 오토메이션 포함(Include Volume/Pan Automation)**: 체크 해제합니다.
   - 저장 위치는 `raw/`로 합니다.
2. **처리본(processed)**
   - 같은 메뉴에서 이번에는 **이펙트 플러그인 우회**를 체크 해제하고, **볼륨/팬 오토메이션 포함**은 체크합니다.
   - 저장 위치는 `processed/`로 합니다.
   - 처리본은 **페이더와 팬까지 적용된 상태**여야 합니다. 그래야 리버브 센드 양을 정확히 계산할 수 있어요.
3. **리버브·딜레이 리턴(returns)**
   - "모든 트랙 내보내기"는 트랙 영역에 있는 채널만 내보냅니다.
   - 그래서 먼저 믹서에서 Aux 채널을 선택하고, 그 채널 스트립에 대한 트랙을 만들어 트랙 영역에 올립니다.
   - 그다음 2번(처리본)과 같은 설정으로 내보내고, Aux 파일만 `returns/`로 옮깁니다.
   - 센드가 없는 곡이면 이 단계는 건너뜁니다.
4. **믹스**
   - 파일 › 바운스 › 프로젝트 또는 섹션으로 마스터 채널을 바운스합니다.
   - 마스터링 플러그인을 끈 버전을 `곡이름_Mix.wav`로 저장합니다.
   - 마스터링한 버전이 있으면 `곡이름_Master.wav`로 함께 넣습니다.

같은 이름 규칙을 지키려면 Logic의 기본 파일 이름(트랙 번호 + 트랙 이름)을 두 번 모두 그대로 쓰면 됩니다. 2번과 3번에서는 **오디오 꼬리 포함(Include Audio Tail)**도 켜 두세요. 메뉴와 옵션 이름은 Logic 버전과 언어 설정에 따라 조금 다를 수 있습니다.

> 다른 DAW도 같은 원리입니다. "모든 트랙 내보내기"를 한 번은 이펙트 없이, 한 번은 이펙트와 페이더를 넣고 실행하면 됩니다.

## 4. 실행

```bash
# macOS 패키지에 들어 있는 도구를 쓰거나, 직접 빌드한 build/core/ 의 도구를 씁니다.
./smix_learn_mix --genre CCM --out CCM.smxgenre songs/
```

- 트랙마다 학습된 처리와 **fit**(재현 오차, dB)이 표시됩니다. 보통 1~2 dB 이하가 정상입니다. 크게 나오는 트랙은 정렬이 어긋났거나, 처리본에 다른 트랙 소리가 섞인 경우예요.
- 곡마다 **reconstruction fit**(처리본으로 완성 믹스를 얼마나 설명하는지)이 표시됩니다. 낮으면 버스 처리나 내보내지 않은 리턴이 있다는 뜻입니다.
- 속도: 트랙당 5~10초 정도 걸립니다(Apple Silicon 기준 추정). 16트랙 × 8곡이면 10~20분입니다.
- 메모리: 한 번에 한 트랙의 원본과 처리본만 메모리에 올립니다.

**학습하는 것**

- EQ: 처리 전후 1/3옥타브 톤 변화를 측정하고, 내장 EQ(로우컷 + 셸프 2 + 피크 4 + 하이컷)로 맞춥니다.
- 게이트, 디에서, 컴프, 새츄레이션, 엔벨로프, 인서트 리버브: 후보 설정을 내장 처리기로 원본에 실제로 적용해 보고, 처리본과 가장 비슷한 값을 고릅니다.
- 리턴 리버브: 소스가 멈춘 구간의 감쇠로 리버브 길이를 재고, 트랙별 센드 양을 같은 효과의 인서트 믹스 값으로 바꿉니다.
- 스레숄드는 입력 라우드니스 기준 상댓값으로 저장되므로, 녹음 레벨이 다른 새 곡에도 적용됩니다.
- 같은 역할(예: 리드 보컬)의 여러 트랙은 중앙값으로 합칩니다.

## 5. 악기 인식 모델(선택)

같은 실행에서 `ear-tracks.csv`가 만들어집니다.

```bash
./smix_ear_features features.csv --list ear-tracks.csv
python training/ear/train_ear.py features.csv ear.smxear
```

자세한 내용은 [README.md](README.md)의 3장을 보세요.

## 6. 만든 파일을 둘 곳

| 파일 | 위치 (macOS) |
|---|---|
| `CCM.smxgenre` | `~/Library/Application Support/SoundManagerAI/models/` |
| `ear.smxear` | 같은 폴더 |
| `smix-intent.gguf` (언어 모델) | 같은 폴더 |

이 폴더는 플러그인 설치 스크립트가 만들고 Finder로 열어 줍니다. 플러그인의 **모듈·설정** 탭에서 불러온 장르 프로필과 악기별 학습 결과를 확인할 수 있습니다.
